# OptiScaler Manager 0.2.0-preview.3

- Expert settings now display the raw value in an editable text field with a separate preset menu. This fixes the non-editable, invisible-value ComboBox behavior.
- Expanded Chinese explanations, preserving technical names and showing the project’s original `OptiScaler.ini` comments. Undocumented entries are labeled as inferences.
- Detail panel explains purpose, current value, common choices, risks, and documentation basis.
- 16 core tests passed at packaging time.

Manager-only package. No OptiScaler DLL, third-party runtime, or game files are included.
