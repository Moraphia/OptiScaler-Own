# OptiScaler Manager 0.2.0

First stable manager release for the independent `Moraphia/OptiScaler-Own` channel.

- Separate manager and game-package update entries; stable Releases only.
- Validate each ZIP against a paired SHA-256 manifest before extraction.
- Improved expert settings explanations, editable values, and preset contrast.
- Manager configuration and installation previews remain local and require confirmation.

This Release contains **only the manager**. It does not include `OptiScaler.dll`, the `Package/` directory, or NVIDIA/other third-party runtime DLLs. Game-package updates will remain unavailable until a separately reviewed and tested package is published. Windows x64 and .NET 8 Desktop Runtime are required.
